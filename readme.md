# Musivo Releases

**Official releases and updates for Musivo.**

Welcome to the official release repository for **Musivo**, your music streaming experience. This repository hosts the latest Windows installers and update metadata used by Musivo's built-in automatic update system.

## 📥 Download Musivo

Visit the [Latest Release](https://github.com/arp1tkm/Musivo-Releases/releases/latest) to download the latest Windows installer.

1. Open the latest release.
2. Download the `.exe` installer.
3. Run the installer and follow the setup instructions.
4. Launch Musivo and enjoy your music.

## 🔄 Automatic Updates

Musivo includes an automatic update system powered by [electron-updater](https://www.electron.build/auto-update).

When a new version is published:

- Musivo checks for available updates.
- You'll be notified when an update is available.
- Download the update directly through the application.
- Restart Musivo to install the latest version.

You don't need to manually download every update.

## 📦 Release Files

Each release may include:

| File | Description |
|---|---|
| `.exe` | Windows installer |
| `latest.yml` | Update information used by electron-updater |
| `.blockmap` | Supports differential updates and optimized downloads |

**Note:** Keep all generated update metadata and installer assets attached to their corresponding GitHub release.
